# Dynastie Royale

Projet de site web pour la Dynastie Royale (Royaume de Porto-Novo).

## Description
Ce site présente l'histoire et les récits des grandes lignées royales du Bénin, incluant :
- Le Royaume de Porto-Novo
- Les Rois de Porto-Novo
- Le Royaume d'Abomey
- Le Royaume d'Allada
- Le Royaume de Kétou

## Technologies
- HTML5 / CSS3
- Bootstrap
- PDF.js pour la visualisation des documents historiques
